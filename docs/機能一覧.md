# 機能一覧

[← 要件定義に戻る](./要件定義.md)

機能ごとの詳しい仕様（入力項目・処理の流れ・API・エラー）は、各機能の機能定義書を参照。画面IDは [画面設計](./画面設計.md) を参照。

| ID | 機能名 | 概要 | 対象画面 | 優先度 | 機能定義書 |
|---|---|---|---|---|---|
| F-01 | 新規登録 | 名前・@ユーザーID・メールアドレス・パスワードを入力して、自分でアカウントを作る | S-02 | 高 | [F-01](./機能定義書/F-01_新規登録.md) |
| F-02 | ログイン・ログアウト | メールアドレスとパスワードで認証する。ヘッダーからログアウトする | S-01, 全画面（ログアウト） | 高 | [F-02](./機能定義書/F-02_ログイン・ログアウト.md) |
| F-03 | タイムライン | 自分とフォロー中ユーザーの投稿を新しい順に表示する。各投稿にいいね数・コメント数を出す | S-03 | 高 | [F-03](./機能定義書/F-03_タイムライン.md) |
| F-04 | 投稿作成 | テキスト（1〜280文字）を投稿する。画像を最大4枚添付してもよい | S-04 | 高 | [F-04](./機能定義書/F-04_投稿作成.md) |
| F-05 | コメント | 投稿詳細画面で、コメントの一覧表示と投稿をする | S-05 | 高 | [F-05](./機能定義書/F-05_コメント.md) |
| F-06 | いいね | いいね／いいね解除をする。いいね数を表示する | S-03, S-05, S-06 | 高 | [F-06](./機能定義書/F-06_いいね.md) |
| F-07 | フォロー | 他のユーザーをフォロー／フォロー解除する | S-06, S-07 | 高 | [F-07](./機能定義書/F-07_フォロー.md) |
| F-08 | ユーザーページ | 特定ユーザーの投稿一覧、フォロー数、フォロワー数を表示する | S-06 | 中 | [F-08](./機能定義書/F-08_ユーザーページ.md) |
| F-09 | ユーザー検索 | @ユーザーIDまたは名前の部分一致で、ユーザーを探す | S-07 | 中 | [F-09](./機能定義書/F-09_ユーザー検索.md) |
| F-10 | 投稿編集 | 自分の投稿の本文・画像を変更する。「編集済み」と表示する | S-04（編集モード） | 中 | [F-10](./機能定義書/F-10_投稿編集.md) |
| F-11 | 投稿削除 | 自分の投稿を、確認のうえ削除する（画像・コメント・いいねも一緒に消える） | S-08 | 中 | [F-11](./機能定義書/F-11_投稿削除.md) |

> F-10・F-11 は投稿者本人だけが使える。他人の投稿には編集・削除のメニューを出さず、API でも投稿者かどうかを確認する。

## 作らない機能

コンセプト（[要件定義 4章](./要件定義.md#4-コンセプトと差別化)）に合わせて、次の機能は作らない。

| 機能 | 理由 |
|---|---|
| インプレッション数の表示 | 見られた数を気にせず投稿できるようにするため |
| リツイート・引用 | 拡散の仕組みを持たないため |
| トレンド・おすすめ表示 | 時系列とフォロー関係だけでタイムラインを作るため |

## API 一覧

各機能定義書に書いた API をまとめたもの。パスはすべて `/api` から始まる。

| 機能 | メソッド | パス | 概要 | ログイン |
|---|---|---|---|---|
| F-02 | GET | `/api/auth/csrf` | CSRF トークンの Cookie を発行 | 不要 |
| F-01 | POST | `/api/auth/signup` | 新規登録（成功したらそのままログイン） | 不要 |
| F-02 | POST | `/api/auth/login` | ログイン | 不要 |
| F-02 | POST | `/api/auth/logout` | ログアウト | 必要 |
| F-02 | GET | `/api/auth/me` | ログイン中のユーザー情報を取得 | 必要 |
| F-03 | GET | `/api/timeline` | タイムラインを取得 | 必要 |
| F-04 | POST | `/api/posts` | 投稿を作成（画像付き可） | 必要 |
| F-05 | GET | `/api/posts/{postId}` | 投稿詳細を取得 | 必要 |
| F-05 | GET | `/api/posts/{postId}/comments` | コメント一覧を取得 | 必要 |
| F-05 | POST | `/api/posts/{postId}/comments` | コメントを作成 | 必要 |
| F-06 | PUT | `/api/posts/{postId}/like` | いいねする | 必要 |
| F-06 | DELETE | `/api/posts/{postId}/like` | いいねを解除する | 必要 |
| F-07 | PUT | `/api/users/{username}/follow` | フォローする | 必要 |
| F-07 | DELETE | `/api/users/{username}/follow` | フォローを解除する | 必要 |
| F-08 | GET | `/api/users/{username}` | ユーザー情報を取得 | 必要 |
| F-08 | GET | `/api/users/{username}/posts` | ユーザーの投稿一覧を取得 | 必要 |
| F-09 | GET | `/api/users/search?q=` | ユーザーを検索 | 必要 |
| F-10 | PATCH | `/api/posts/{postId}` | 投稿を編集（本人のみ） | 必要 |
| F-11 | DELETE | `/api/posts/{postId}` | 投稿を削除（本人のみ） | 必要 |

> いいね・フォローに `PUT` / `DELETE` を使うのは、何回送っても結果が同じになる（冪等）ようにするため。連打しても2重に登録されない。
